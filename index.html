내모음으로 보내기 버튼

Keep 목록에서 누르면 보이는 링크를 하나씩, 다른 사이트에서 누르면 그 페이지를 링크로 저장해요. 글을 긁어 선택하고 누르면 그 글만 저장해요. 직접 누를 때만 동작하고, 계정 정보는 쓰지 않아요.

＋ 내모음으로 보내기
  1. ＋ 내모음으로 보내기를 북마크바로 끌어다 놓아요.
  2. Keep 화면에서 그 버튼을 누르면 목록을 끝까지 내리며 모아요.
  3. 다 모이면 나오는 내모음으로 보내기를 누르고, 새 탭에서 저장하기를 눌러요.

이미지를 끌어다 놓거나 눌러서 선택 스크린샷을 복사했다면 이 페이지 아무 곳에서나 붙여넣기 해도 됩니다 · 여러 장 가능

읽은 글은 '링크·글 붙여넣기' 칸으로 옮겨집니다. 거기서 확인하고 저장하세요.

내보낸 저장 목록 파일을 끌어다 놓거나 눌러서 선택 .html · .json · .csv · .txt 안의 링크를 모두 찾아냅니다
  • 크롬 즐겨찾기: 주소창에 chrome://bookmarks 입력 → 오른쪽 위 ⋮ → 북마크 내보내기 → 저장된 .html 파일을 여기에 올리세요. 폴더 이름은 태그가 됩니다.
  • 유튜브 재생목록: 재생목록 페이지를 열고 끝까지 내린 뒤 전체 선택(Ctrl+A)·복사해서 '링크·글 붙여넣기'에 붙이면 영상 제목과 링크를 뽑습니다. 목록 전체는 Google 테이크아웃(takeout.google.com) → YouTube → 재생목록 .csv를 여기에 올려도 됩니다.
  • 네이버 지도: 저장한 장소에서 공유 → 복사한 문구([네이버 지도] 장소 이름, 주소, 링크)를 그대로 붙여넣으면 '장소'로 저장됩니다. 여러 곳을 이어 붙여도 됩니다.
  • 구글 지도: takeout.google.com에서 '저장됨'(장소 목록 .csv)과 '지도(내 장소)'(저장된 장소.json)를 골라 내보낸 뒤 그 파일들을 여기에 올리세요. 목록 이름 파일 여러 개를 한 번에 올려도 됩니다.
  • 네이버 Keep: 내보내기 기능이 없어요. Keep 화면에서 메모를 선택·복사해 붙여넣으세요. 링크가 여러 개면 한 번에 나눠 저장합니다.
  • 직접 입력: 링크만, 또는 "제목 링크"나 윗줄 제목 + 아랫줄 링크 형태로 여러 줄 붙여넣으세요.
